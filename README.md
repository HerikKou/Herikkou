## Sobre mim

Desenvolvedor backend com foco em **Java + Spring Boot**, com experiência prática em arquitetura de **microsserviços**, mensageria com **Apache Kafka**, observabilidade com **Datadog** e containerização com **Docker**.

Formado em **Análise e Desenvolvimento de Sistemas** pela Universidade de Mogi das Cruzes (UMC). Tenho background em bootcamp intensivo com trabalho em equipe real — modelagem de dados, controle de acesso, testes, documentação e divisão de responsabilidades. Sigo boas práticas no dia a dia: código limpo, testes automatizados, documentação técnica e integração contínua.

Minha evolução tem sido guiada por projetos reais onde performance, rastreabilidade e qualidade não são opcionais.

## Projetos em Destaque

### 🔐 Sistema de Antifraude com Observabilidade
> **Repositório:** [github.com/HerikKou/ProjetoAntifraude](https://github.com/HerikKou/ProjetoAntifraude)

Sistema de detecção de fraudes em transações financeiras com **observabilidade completa** via Datadog.

**Destaques técnicos:**
- Arquitetura baseada em **microsserviços** com comunicação assíncrona via **Apache Kafka**
- Observabilidade end-to-end: **logs estruturados, métricas e traces distribuídos** no Datadog
- **Dashboards customizados** para monitoramento de performance e detecção de anomalias em tempo real
- Containerização completa com **Docker Compose** e CI/CD via **GitHub Actions**
- Testes automatizados com **JUnit + Mockito** cobrindo regras de negócio críticas

`Java 17` `Spring Boot` `Apache Kafka` `Datadog` `Docker` `GitHub Actions` `JUnit` `Mockito`

---

### 🏦 Processamento Bancário em Microsserviços
> **Repositório:** [github.com/HerikKou/Processamento_Bancario](https://github.com/HerikKou/Processamento_Bancario)

Plataforma de processamento bancário construída sobre arquitetura de **4 microsserviços independentes**.

**Destaques técnicos:**
- Cada serviço possui **banco de dados isolado** (database-per-service pattern)
- Comunicação assíncrona com **Kafka** para garantir consistência eventual entre serviços
- Deploy em ambiente **AWS (EC2 + S3)** com containers Docker
- **Documentação técnica e funcional completa** de todos os serviços e contratos de API
- Rastreamento de eventos e auditoria de transações entre os serviços

`Java 17` `Spring Boot` `Apache Kafka` `PostgreSQL` `MySQL` `Docker Compose` `AWS`

---

### 🔑 Autenticação com JWT e Spring Security
> **Repositório:** [github.com/HerikKou/Autentica-o-via-JWT-token-](https://github.com/HerikKou/Autentica-o-via-JWT-token-)

Implementação de autenticação e autorização segura com tokens **JWT** e **Spring Security**.

**Destaques técnicos:**
- Fluxo completo de **login, geração e validação de token JWT**
- Controle de acesso por roles com **Spring Security**
- Senhas com BCrypt, expiração de token e refresh token

`Java` `Spring Boot` `Spring Security` `JWT` `MySQL`
